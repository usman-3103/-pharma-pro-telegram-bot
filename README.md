# Pharma.Pro Telegram Bot — финальная версия

Возможности:

- один препарат;
- список препаратов одним сообщением;
- подбор турецкого аналога;
- текст, фотографии и документы;
- подтверждение перед отправкой;
- номер и источник запроса;
- имя, username и ссылка на профиль;
- связь с оператором;
- Health Check для Render.

Render:

- Build Command: `pip install -r requirements.txt`
- Start Command: `python main.py`
- Environment: `BOT_TOKEN`
- Тип сервиса: Web Service
